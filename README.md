## 简历里的三段实习

### 叠纸游戏｜《无限暖暖》

《无限暖暖》是 UE 开发的换装开放世界手游，重点在探索、解谜、服装收集和角色养成。我在叠纸负责 3.1「青蛙战斗」活动数值和 3.0 怪物奖励，具体涉及活动商店、成长曲线、技能收益、12 关 Boss 强度、配置验证和复盘。

- 项目页：[青蛙战斗｜强数值活动的战斗与奖励闭环](docs/frog-project.md)
- 关键结果：279 个战斗情形覆盖，12 关和 324 条合法路线通过

### 完美世界｜欧美卡通二合

这是一款面向欧美市场的卡通二合手游。用户通过订单获得 Token / 棋子，合成后推进积分、阶段、通行证和图鉴。我负责活动系统、棋子与订单机制、表现需求和验证，也参与了 Chess & Board、多倍合成、障碍、溢出和棋盘暂存的设计。

- 项目页：[二合活动｜从玩法理解到项目落地](docs/merge-project.md)
- 结果：形成可复用活动框架和验收基线；线上效果尚未验证

### 微派网络｜《贪吃蛇大作战》

《贪吃蛇大作战》是一款以吞噬成长、碰撞生存和多人竞技为核心的休闲手游。我在微派做新玩法和试玩广告，独立完成 3 款上线版本，单款累计消耗 3 万元，ROAS 7d 达到 10%。

- 项目页：[试玩广告｜把 30 秒广告做成可玩原型](docs/trial-ad.md)
- 我关注的问题：用户能不能立刻看懂、第一次操作有没有反馈、失败后愿不愿意再来一次

## 我平时怎么做事

接需求时先对齐目标、约束和验收人。先把最小闭环跑通，再看要不要扩内容和表现。配置表除了数值，还会检查字段、ID、引用、状态流转、异常补偿和前后端边界。验收不只看“请求发出”，还会看日志、实机结果和玩家反馈。

AI 主要用来查漏、批量处理、写测试和做原型。创意、取舍和最终验收还是自己负责。具体流程放在：[效率系统｜AI、Lua、命令行](docs/efficiency-system.md)。
