## 实习经历

### 叠纸游戏｜数值策划实习生｜《无限暖暖》

2026.08—至今，上海。

《无限暖暖》是一款 UE 开发的换装开放世界游戏，核心体验为探索解谜、服装收集。我负责 3.1 战斗活动数值与 3.0 怪物奖励：商店限购是节奏工具，决定玩家每天回来的理由；由材料投放与等级推出时间—战力，再按同阶段基准、TTK 与容错次数反推 12 关 Boss 强度。30 级是时间、材料、战力、怪物、技能五个系统的共同刻度，需同时满足活动尾段成长、约 60% 战力通关与材料整数约束。

攻速改版后拒绝一刀切除以 1.65，按直伤、灼烧、控制、护盾、吸血分别重标；20 个技能按乘区与覆盖率等效、随解锁递增。验证自己闭环：批量模拟看分布与尾部，GM / Lua 实机抽检，服务器日志核对到账——请求发出不算成功；配置缓存问题先兜底再推动逻辑拆分。

### 完美世界｜系统策划实习生｜欧美卡通二合

2026.07—2026.08，北京。

在既有 Reward / Shop / Popup 框架上设计限时二合，复用 15 表新增 10 表。竞品验证的是需求成立，不是可复制的棋盘：重新求解每日生成次数、棋子权重、订单深度与棋盘容量，把生成、转换、需求、空间、奖励当作同一系统。棋盘空间是隐藏资源，障碍、溢出、暂存调节继续合成机会、整理成本与付费/等待动机；多倍合成同步控产出与订单膨胀。

按控制流—配置—表现—异常四层验证；客户端负责体验、服务器负责货币与奖励权威；与程序、美术、QA 对齐字段与验收口径，成果是系统实现与测试覆盖。

### 微派网络｜游戏策划实习生｜《贪吃蛇大作战》

2026.03—2026.07，武汉。

主要参与新玩法和发行试玩广告。独立产出 3 款上线试玩广告并完成数据分析，单款累计消耗 3 万元，ROAS 7d 10%。工作包括 30 秒原型、营销视频、传播素材、后台配置、测试和上线，也参与新玩法设计、Cocos 原型和提效工具整理。

## 项目经历

### [青蛙战斗｜3.1 活动战斗数值](docs/frog-project.md)

活动用商店限购推动养成，再由 12 关 Boss 检验战力。我负责商店、成长、技能、怪物和奖励，从玩家各阶段能达到的等级与资源反推怪物强度。

攻速调整后，按 31 个属性等级、3 种战斗时长和 3 个槽位展开 279 个战斗情形，分别处理直伤、灼烧、护盾、控制和吸血。完成 12 关配置检查及 324 条合法路线模拟。这些结果用于验证规则与配置可达性，不等同于真人胜率或线上留存。

### [二合活动｜限时二合系统](docs/merge-project.md)

活动通过订单获得 Token / 棋子，合成后推进积分、阶段、通行证和图鉴。我负责活动需求、玩家分层、棋子权重、订单 / Token、积分 / 通行证 / 图鉴与异常补发，同时处理表现、交互和前后端边界。

最终形成可替换主题、棋子、棋盘和奖励的活动框架与验收基线。项目尚未做线上效果验证。

### [试玩广告｜30 秒可玩原型](docs/trial-ad.md)

独立完成选题、30 秒原型、营销视频、投放素材和后台配置，按 CTR / CVR / CPM / ROAS 迭代版本。设计上重点处理第一次操作、不同点击速度下的难度，以及“差一点赢”的结束点。

3 款试玩广告上线，单款累计消耗 3 万元，ROAS 7d 10%。
