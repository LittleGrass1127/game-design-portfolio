# 战斗养成｜数值表说明

这是一套活动型战斗养成的数值方案（表内标注为“合成案例 / 公开作品版”）：玩家在活动期内用活动币购买属性与技能材料，提升生命、攻击、攻速和技能等级，按日程挑战普通/精英怪与 3 个 Boss。

本目录公开 2 张与具体活动周期、等级上限无关的表（UTF-8）。“数值总览”“玩家成长”“对手与日程”三张表的逐级 / 逐日数据与活动周期、等级结构强相关，不在公开仓库展示，只在下文用文字概括思路。

## 文件一览

| 文件 | 工作表 | 内容 |
|-|-|-|
| [skills.csv](skills.csv) | 技能 | 20 个被动 + 3 个主动技能，每个被动 Lv.1–3 的倍率、效果、升级消耗和 Lv.3 追加效果 |
| [shop-rewards.csv](shop-rewards.csv) | 商店与奖励 | 商店材料价格/折扣/限购、训练签抽取概率与期望价值、技能升级消耗、技能收集奖励、击败奖励 |
| （未公开） | 数值总览 / 玩家成长 / 对手与日程 | 内容规模与战斗状态参数；逐级属性与材料；对手属性与逐日经济日程 |

## 主要字段

- **HP / ATK / AS**：生命、攻击、攻击速度。AS 是“点数”，不是每秒攻击次数。
- **实际攻击间隔**：由基础攻击间隔和 AS 换算得到，带 1 秒下限。
- **专材**：属性专用材料（生命/攻击/速度训练模块），商店同价出售。
- **普通 / 稀有 / 史诗（核心）采集物**：战斗与采集获得的辅助材料，用于升级与技能升级。
- **高手日 / 标准日 / 休闲日**：三类投入程度的玩家预计在第几天击败该对手。
- **推荐 H/A/S**：挑战该对手时推荐的生命 / 攻击 / 攻速等级。
- **HP 倍率**：怪物 HP ÷ 推荐时玩家 HP。
- **目标战时**：设计期望的单场战斗时长（秒）。
- **基础倍率 / 条件倍率**：技能伤害系数；条件倍率在满足条件（目标有减益、自身有护盾、目标被标记、目标低血等）时替代基础倍率。
- **-20% / -10% / +10%**：商店材料每日价格浮动后的价格（大降 / 小降 / 涨价）。

## 表之间的关系

1. **数值总览**（未公开）汇总其余各表的关键参数，是整套方案的入口。
2. **玩家成长**（未公开）给出每升一级的属性和材料消耗；**商店与奖励** 给出材料价格，两者相乘得到三段升级的币值（汇总在玩家成长表底部）。
3. **对手与日程**（未公开）中每个对手的“玩家 HP / ATK / AS”取自玩家成长表对应等级，怪物属性再按 HP 倍率和目标战时反推。
4. **对手与日程** 下半部分把每天的收入（外部币、击杀币）和支出（属性专材、技能升级）逐日结算，验证币余额和采集物余额始终不为负。
5. **技能** 的开放节点（开局 / 节点 A 前 / 完成节点 A / 完成节点 B）对应 Boss 首通解锁：第一个 Boss 解锁稀有被动和第二个主动，第二个 Boss 解锁史诗被动和第三个主动。技能升级消耗与商店表中的“技能升级消耗”一致。

## 从表里看出的数值设计思路

- **线性属性 + 非线性间隔**：HP 每级 +24、ATK 每级 +0.55、AS 每级 +0.9，均为线性；实际攻击间隔 = 基础间隔 4.4 秒 ÷ (1 + AS/10)，所以攻速越往后收益越平缓，并有 1 秒下限，避免攻速无限堆叠。
- **三段式材料曲线**：升级分三段，每级专材消耗 1 → 2 → 3，后段额外需要稀有采集物；直接币消耗为 0，币只用来买材料，养成成本全部通过商店收口。
- **按玩家反推怪物**：普通/精英怪 HP 倍率在 1.00x–1.11x、目标战时约 29–39 秒；3 个 Boss 的 HP 倍率逐步升到 1.12x / 1.32x / 1.48x，目标战时 44 / 53 / 61 秒，减伤也从 0% 逐步到 10%，难度靠倍率和时长拉开，而不是突然跳变。
- **三档投入节奏**：每个对手都给出高手 / 标准 / 休闲三档的预计击败日；前期三档基本同步，后期休闲档逐渐拉开，最终 Boss 的击败日相差数天，保证低投入玩家在活动结束前也能通关。
- **逐日经济校验**：标准日程中每日固定外部币 + 击杀/首通币，与属性和技能支出逐日对账，币余额在 Boss 日前后明显下降、之后回升，用 Boss 节点制造“攒资源 → 集中投入”的节奏。
- **训练签保持正期望**：训练签 450 币/次且不参与折扣；按原价估值期望价值为 580.5（129% 票价），即使按 -20% 估值也有 464.4（103.2%），保证抽签对玩家始终不亏，避免变成陷阱选项。
- **商店价格浮动 + 每日限购**：材料每日按大降 / 小降 / 涨价浮动并按天新增库存，给玩家“今天买还是明天买”的轻决策，同时用活动总限控制总产出。
- **技能成长与流派**：被动每升一级基础倍率约 +5%（高额伤害型约 +10%）；稀有/史诗技能在 Lv.3 获得追加效果，并通过余热、易伤、减速、护盾、标记、低血等条件倍率形成联动；战斗状态数值（灼烧层数上限、护盾上限、单次吸血上限、动作倍速上限）统一封顶，防止叠加失控。
- **收集奖励回流**：技能收集数达到阶段时返还活动币、训练签赠票和采集物，鼓励玩家尝试更多技能而不是只升一个。
