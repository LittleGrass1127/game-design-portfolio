# 《农场物语》游戏策划案

> 说明：本文为参考经典农场游戏（星露谷物语）的复刻练习，部分角色与内容沿用原作设定，仅用于策划练习。

> 参考作品：星露谷物语（Stardew Valley）、牧场物语、动物森友会
> 目标平台：移动端 + PC

配套文档：[【需求文档】农场物语](requirements.md)

---

## 一、游戏概述

### 1.1 描述

一款像素风农场经营 + 小镇社交模拟游戏，玩家继承爷爷的破旧农场，通过耕种、养殖、采矿、钓鱼、社交，将农场恢复生机并融入小镇生活。

### 1.2 核心体验

| 体验维度 | 说明 |
|-|-|
| **治愈感** | 远离喧嚣，在自己的农场按自己的节奏生活 |
| **成长感** | 从一块荒地到繁荣农场，每天都能看到变化 |
| **探索感** | 小镇里的秘密、矿井深处的宝藏、村民背后的故事 |
| **归属感** | 和小镇居民建立关系、参与节日、找到家的感觉 |
| **自由感** | 没有强制目标，你想种地就种地，想钓鱼就钓鱼 |

### 1.3 目标用户

| 用户类型 | 特征 | 规模 |
|-|-|-|
| 休闲玩家 | 每天玩30分钟，放松为主 | 最大群体 |
| 模拟经营爱好者 | 追求效率最大化、全图鉴 | 核心群体 |
| 社交剧情党 | 沉迷NPC故事和恋爱线 | 次要群体 |
| 收集党 | 钓鱼全图鉴、博物馆全收集 | 长尾群体 |

## 二、核心玩法

### 2.1 核心循环

```Plaintext
起床 → 看天气/日历 → 规划今日行动
  → 耕种（浇水/播种/收获）
  → 养殖（喂食/收集/抚摸）
  → 采集（采矿/钓鱼/觅食）
  → 社交（送礼/对话/任务）
  → 建造（升级工具/扩建农场/装修房屋）
  → 回家睡觉 → 存档 → 新的一天
```

### 2.2 核心玩法模块

| 模块 | 玩法说明 | 玩家驱动力 |
|-|-|-|
| **耕种** | 翻地→播种→浇水→施肥→收获→售卖 | 成长感、收获满足感 |
| **养殖** | 建造畜棚→购买动物→喂养→收集产品 | 养成感、被动收入 |
| **采矿** | 矿井探索→击败怪物→收集矿石和宝石 | 探索、风险收益、成长 |
| **钓鱼** | 抛竿→等待→拉钩小游戏→获得鱼类 | 技巧挑战、收集 |
| **觅食** | 地图上采集野果/木材/石材 | 补充资源、季节限定 |
| **烹饪** | 收集食材→学习食谱→制作料理 | 增益效果、送礼、收集 |
| **建造** | 升级农舍→建造畜棚/鸡舍/鱼塘→装修 | 进度感、个性化 |
| **社交** | 和村民对话→送礼→触发剧情→恋爱结婚 | 情感连接、故事驱动 |
| **节日** | 每月1-2个节日，小游戏+社交+限定商品 | 仪式感、稀缺性 |

### 2.3 季节系统

| 季节 | 月份 | 特色作物 | 特色活动 | 天气 |
|-|-|-|-|-|
| 春 | 第1-28天 | 草莓、土豆、花椰菜 | 复活节、花舞节 | 多雨 |
| 夏 | 第29-56天 | 蓝莓、玉米、向日葵 | 夏日夜市、沙滩节 | 晴天为主 |
| 秋 | 第57-84天 | 南瓜、蔓越莓、葡萄 | 丰收节、万灵节 | 多风 |
| 冬 | 第85-112天 | 冬季种子（温室除外） | 冰雪节、冬星节 | 多雪 |

## 三、系统设计

### 3.1 时间系统

| 参数 | 设计 |
|-|-|
| 一天实际时长 | 约13分钟（可暂停/加速） |
| 起床时间 | 6:00 AM |
| 入睡时间 | 2:00 AM（超过会晕倒） |
| 每小时 | 约43秒 |
| 季节 | 28天/季 |
| 每年 | 112天 |

### 3.2 体力系统

| 参数 | 数值 |
|-|-|
| 初始最大体力 | 270 |
| 每吃一个星落果 | +34上限 |
| 体力恢复方式 | 睡觉（满）、吃东西、泡温泉 |
| 体力消耗 | 使用工具消耗2-4点，耕地/钓鱼/采矿较多 |

**设计意图**：体力限制迫使玩家做选择——今天去采矿还是钓鱼？不能什么都做，创造了「明天的期待」。

### 3.3 经济系统

| 收入来源 | 说明 |
|-|-|
| 农作物销售 | 核心收入，季节性波动 |
| 动物产品 | 鸡蛋/牛奶/羊毛/松露，稳定被动收入 |
| 加工品 | 奶酪/果酱/酒，加工提升价值 |
| 采矿 | 宝石/矿石直接售卖 |
| 钓鱼 | 鱼直接售卖 |
| 觅食 | 季节限定野果/贝壳 |

**经济循环设计**：

```Plaintext
劳动→获得原材料→售出获得金币→购买种子/工具/建筑→扩大生产→更多收入
```

### 3.4 升级系统

| 升级线 | 等级 | 升级方式 | 解锁内容 |
|-|-|-|-|
| 耕种 | 0-10 | 收获作物 | 解锁配方/配方效率 |
| 采矿 | 0-10 | 采矿+打怪 | 解锁配方/矿石提炼 |
| 觅食 | 0-10 | 砍树+采集 | 解锁配方/野果生长 |
| 钓鱼 | 0-10 | 钓鱼 | 解锁鱼竿/减少难度 |
| 战斗 | 0-10 | 击杀矿井怪物 | 解锁配方/伤害提升 |

| 工具升级 | 铜→铁→金→铱 | 消耗金币+矿石 | 减少体力消耗/增加范围/提高效率 |
|-|-|-|-|

### 3.5 社交系统

| 维度 | 设计 |
|-|-|
| 可交往NPC | 12人（6男6女），各有故事线和喜好 |
| 好感度 | 0-10心，通过对话+送礼+完成任务积累 |
| 好感事件 | 2/4/6/8/10心触发专属剧情 |
| 恋爱 | 8心后可以表白，10心结婚 |
| 结婚后 | 配偶搬入农场，偶尔帮忙做家务 |
| 生日 | 每个NPC有固定生日，当天送礼效果8倍 |

### 3.6 收集系统

| 收集内容 | 说明 |
|-|-|
| 出货全图鉴 | 所有可售卖的物品都出货一次 |
| 鱼类全图鉴 | 所有可钓到的鱼，含季节/天气/地点限制 |
| 矿物全图鉴 | 所有矿石和宝石 |
| 料理全图鉴 | 所有可烹饪的料理 |
| 博物馆捐赠 | 捐赠文物和矿石，填满博物馆 |

## 四、商业化设计

| 模式 | 说明 |
|-|-|
| **付费下载** | 本体买断制，PC 48元 / 移动端 30元 |
| **皮肤DLC** | 农场外观皮肤、家具套装，不影响数值，9-18元/套 |
| **宠物DLC** | 新品种宠物（猫/狗/兔子/鹦鹉），12元/种 |
| **扩展包** | 新地图+新作物+新NPC（如海岛农场），18元 |
| **无内购抽卡** | 保持纯粹的单机体验，不破坏节奏 |
