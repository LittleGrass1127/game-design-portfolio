# 游戏分析与用户理解

> 只写设计分析和对玩家的理解：几款游戏的系统与运营判断、原神抽卡经济、SLG 设计对比、星穹铁道数值分析，以及从中沉淀的分析框架。

---

## 一、分析框架

看一款游戏时，我按四层拆：

1. **体验目标**：玩家应该感到紧张、成长、陪伴、爽快，还是被策略理解？
2. **核心循环**：玩家每局做什么、为什么回来、什么行为形成长期目标？
3. **控制变量**：成长、资源、概率、时间、操作、社交和内容供给中，哪些是主要杠杆？
4. **验证口径**：用模拟、实机、日志、数据和玩家反馈交叉验证，避免把平均通关误当成完整体验。

这套框架也用来判断“为什么不抄”：竞品只提供已经验证的需求，不能替代对目标用户、差异能力、开发成本和失败退路的判断。

## 二、游戏设计分析

### 炉石传说：平衡不是把所有卡组调到 50% 胜率

把线下 TCG 玩法搬到线上，画面、配音和玩法都很精致。每日任务改版过一次，改为三天任务栏，贴合休闲游戏定位。乐趣来自卡组博弈和随机性；卡牌描述简洁直白。问题在于长线运营中卡牌越来越超模，容错率降低。

炉石的环境由卡组生态、先后手、信息差、随机性和克制关系共同决定。单纯削最强卡组，可能让另一个极端卡组失去对手；单纯增加随机性，又会让竞技反馈变得不可解释。真正要维护的是“玩家能否理解自己为什么输，以及下一局有没有可执行的调整”。

所以看数值时不只看单体强度，也看组合上限、出现率、对抗关系、学习成本和传播性。对应到系统设计里，就是不能只问“这个功能有没有”，还要问“它在什么条件下会被使用、被误用，以及环境变化后会不会失控”。

完整拆解见 [炉石传说游戏拆解案](hearthstone.md)。

### 原神：强数值玩法怎样不伤害已有用户？

二次元开放世界的开创者，单机化体验。优化了卡池保底，长线运营中角色强度膨胀控制较好；通过角色偶像化的 IP 塑造让玩家为喜爱付费，减少对角色强度的依赖。大世界玩法在 2020 年具有开创性，顺应了时代；元素反应体系简单直观，用元素附着的复杂规则来控制数值膨胀。

值得观察的不只是角色伤害，而是角色获取、养成成本、元素反应、探索内容、版本节奏和情绪陪伴之间的关系。一个强数值玩法如果只靠抬高门槛制造压力，会让“喜欢角色和探索”的用户被排除；如果完全不做数值目标，又无法形成成长验证。设计不是“把怪做难”，而是先确定参与者是谁、愿意投入多少、失败后能否通过策略而非纯数值补齐，让不同投入层级的玩家都能看见下一步。

**抽卡经济分析**：

| 指标 | 数据 |
|-|-|
| 数学期望（不计捕获明光） | 一金 93.446 抽 |
| 免费玩家养成 | 2 个版本养成一个角色 |
| 大小月卡玩家养成 | 一个版本养成一个角色 |
| 计入星辉折扣 | 9 折抽卡 |
| 大小月卡外一金折合 | 1199 元 |

控制每个版本的免费抽数和养成资源；用怪物机制和数值膨胀缓慢消耗老玩家手中的资源；剧诗玩法鼓励玩家多抽卡，形成价格歧视。

原神在 2020 年凭借先发优势和精美画面同时吸引了二次元与非二次元群体（扩圈）；开服阶段的塞尔达争议、疫情期间线下娱乐缺乏，都带来了用户增量，用户增量使游戏膨胀较慢。须弥版本和 4.8 版本出现过舆论争议。长线玩法不可避免地出现“益智小游戏化”的问题；童话幻想画风也让联动较难。

### 崩坏：星穹铁道：伤害之外，还有行动经济

演出动画精美，剧情以番剧化方式更新。可自动战斗，定位为“副游”，简化了养成操作，但仍保留凹分、排轴的上限。数值膨胀剧烈，“主推论”盛行；玩家出现抽卡膨胀焦虑，影响剧情体验。3.x 版本剧情冗长，在快餐化的节奏下难以完整体验。

0T（首轮击杀）的核心不是面板伤害堆高，而是速度、行动提前、能量循环、增益覆盖、目标选择和伤害窗口共同配合。一个角色即使纸面 DPS 很高，如果启动慢、覆盖率低或与队伍轴不匹配，实际贡献也会明显下降。所以做战斗数值时要用“有效生命 / DPS + 覆盖率 + 时间窗口”，而不是只看名义伤害。

### 暗黑破坏神 4

独特的暗黑画风，刷子游戏的核心是“变强的乐趣”：连续升级加点、更换 BD、附魔、强化。赛季进度不卡人，玩家可以较快完成小毕业。买断制游戏玩家群体较小、氪金上限低，玩法也较为硬核。

## 四、星穹铁道 · 深度数值分析

### 核心判断

崩铁是版本中后期膨胀的游戏。本分析评估了「三昔」组合的强度及对环境的适应性。

### 角色数值分析

| 分析维度 | 内容 |
|-|-|
| 倍率与命座 | 昔涟、遐蝶等角色倍率与命座提升 |
| 自拐与群拐 | 分析角色的自拐与群拐能力 |
| 欢愉技机制 | 跑条机制、战技点占模问题 |
| 同谐命途 | 趋于失效的趋势判断 |

### 排轴与配速

通过拉表排轴，对比不同配置下的伤害提升：

| 配置 | 伤害提升 |
|-|-|
| 00（0命无专武） | 基准线 |
| 10 | 提升显著 |
| 11 | 进一步放大 |
| 21 | 质变级提升 |

结论：高金配置下机制重要性大于数值，配速要服务队伍轴而不是单看面板。

### 版本膨胀预测

- 预测 4.2 至 4.6 版本为关键膨胀节点；
- 「通辅」时代消失，未来进入「专拐」时代；
- 非主推玩家的抽卡策略：集中资源追高金配置，利用机制优势对冲数值膨胀。

## 五、对玩家与受众的理解

- 玩家不只消费内容，还会参与解释、传播和再创作。看动漫和长线内容时，关注的是世界观、角色关系、情绪价值和长线陪伴，而不只是单次剧情刺激。
- 短视频和社区内容让“前三秒钩子、节奏、梗传播、评论区反馈和二创空间”变成系统设计也要考虑的因素。
- 一个系统要更容易被理解、更值得讨论、更有二创空间；但“可传播”不能替代“好玩”，最终仍要回到核心循环、反馈和长期目标。

## 六、我想设计什么样的游戏

- **低门槛进入、高上限决策：**前几分钟能理解基本循环，长期靠玩家自己的构筑、顺序和取舍拉开水平，而不是靠隐藏规则制造难度。
- **在成熟品类里做结构创新：**不复制竞品 UI 和功能，先找到未被满足的玩家决策，再用新的资源关系或交互方式形成差异。
- **系统驱动但体验可解释：**短期反馈清楚，长期目标可复盘；数值、系统和内容互相承接，让玩家知道自己为什么赢、为什么输、下一步做什么。
- **允许玩家形成自己的玩法：**给策略、故事、角色和二创留下空间，让玩家不只消费内容，也愿意讨论和创造。
