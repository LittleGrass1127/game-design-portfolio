## 3. 物品和棋盘

| 项目 | 描述 |
|-|-|
| 物品 | 二合后两个原物品消失，在静止不动（被合成）物品的位置生成一个 LV 提高一级的物品；满级物品无法二合，会弹回原位置。物品可以自由移动，选中的格子有蓝色边框；钥匙下锁住的格子无法选中。 |
| 物品溢出 | 物品会溢出一次，溢出后进入“记录溢出”状态，有空格时放置溢出物品。处于记录溢出状态时，若合成将再次溢出物品，提示“合成会导致奖励丢失”；如果仍然合成，只记录最新的溢出物品。即物品最多溢出一次；棋盘满且已有溢出物品时，再手动二合产生额外物品，会提示奖励丢失。 |
| 棋盘 | 放置新生成物品和进行二合的区域。物品生成来源：点击手指消耗合成物；棋盘变化后暂存、点击放置；手动二合额外产生的二级物品、三级物品、奖励物品。 |
| 障碍 | 格子障碍：设下面有物品的为 A，没有物品、表现为栅栏的为 B。A：拖动相同物品二合解锁；B：相邻格子相同物品二合解锁，解锁后变成 A（即需要两次解锁：一次相邻消除，再一次拖动相同物品二合）。一般情况下 B 周围都是 B，最外层是 A。区域障碍：对应的最高 LV 钥匙解锁。 |
| 尺寸 | 7×8（横7格，竖8格） |
| 变化 | 格子解锁；区域解锁；棋盘整体向下移动3行 |
| 变化后处理 | 下方的物品收集暂存到手指按钮处；如果下方有未解锁的格子，自动解锁并释放其中物品，一并暂存到手指按钮处 |

### 积分进度和通行证界面的显示位置

- **默认位置**：游戏根据玩家进度计算出的目标位置；
  - 1级默认位置：1级框在最下 / 最上；
  - 满级默认位置：满级框在最上 / 最下。
- **上一次位置**：玩家上一次滑动界面退出时记录的位置。
- **已记录位置**：通常为上一次位置；在初次进入、升级、重新登录时使用默认位置。
- **打开后显示位置**：使用已记录位置。

默认位置计算规则：

- 定位目标：
  - 如果存在已完成但未领取的等级：定位目标 = 最低的已完成但未领取等级；
  - 如果不存在：定位目标 = 当前正在完成的等级。
- 定位距离：
  - 积分进度界面使用距离下方 x 的定位；
  - 通行证界面使用距离上方 y 的定位；
  - x 和 y 默认均为半个等级框高度；如果不能满足，看当前定位目标更靠近1级还是满级，使用对应的1级默认位置 / 满级默认位置作为保底。
- 默认位置更新：升级。

过程：

## 通行证位置显示逻辑（优化版）

为减少概念重复，位置分为三类：上一次位置是玩家上次退出时保存的位置；默认位置是游戏根据玩家进度计算出的目标位置；已记录位置是当前打开界面实际使用的位置。打开后始终显示已记录位置。

首次进入、升级和重新登录时，已记录位置使用默认位置；普通进入时，已记录位置使用上一次位置。玩家滑动会更新已记录位置，退出时将其保存为上一次位置。升级会重新计算默认位置，并用新的默认位置覆盖已记录位置，升级弹窗同样使用新的默认位置。

| 场景 | 默认位置 | 上一次位置 | 已记录位置与显示结果 |
|-|-|-|-|
| 首次进入 | 一级默认位置 | 不使用 | 已记录位置 = 默认位置，显示一级默认位置 |
| 普通进入 | 不变 | 使用 | 已记录位置 = 上一次位置，显示上一次位置 |
| 玩家滑动 | 不变 | 退出时更新 | 已记录位置更新为滑动后的位置 |
| 普通变化且没有升级 | 不变 | 不变 | 已记录位置不变，页面不自动跳转 |
| 玩家升级 | 重新计算并更新 | 不变 | 已记录位置被默认位置覆盖，页面和弹窗显示新的默认位置 |
| 退出后重新登录 | 使用最近一次升级后的默认位置 | 不使用 | 已记录位置 = 默认位置，显示默认位置 |

### 默认位置计算

定位目标优先选择最低的已完成但未领取等级；如果不存在，则选择当前正在完成的等级。积分进度界面将目标定位在距离页面下方 x 的位置，通行证界面将目标定位在距离页面上方 y 的位置；x 和 y 默认均为半个等级框高度。

如果目标位置无法满足 x 或 y，则根据定位目标更靠近一级还是满级，使用对应的保底位置：积分进度界面中一级在最下、满级在最上；通行证界面中一级在最上、满级在最下。

# 二、交互逻辑

## 1. 玩法

概述：玩家通过主玩法完成订单获得积分，消耗积分将物品放入活动棋盘进行二合；二合会额外产生新的物品和奖励、解锁棋盘格子和区域，并推动剧情进度、进度条、积分和通行证。

- 玩家通过主玩法订单和活动奖励获得活动积分，消耗活动积分将一级物品放入活动棋盘进行二合；
- 一级物品二合逐渐升级到 LV15，过程中获得二级物品钥匙、钻石、书本（二级来源）、面包，以及奖励物品；
  - 奖励物品为体力、金币、货车、帽子。
- 一级物品与格子下的物品二合解锁格子，满级钥匙解锁区域；区域全部解锁后，满级钥匙开启钥匙宝箱，获得奖励物品；
- 首次获得一级物品新的 LV，推进中间的进度条和上方的剧情；一级 LV15 剧情通关，获得纪念品、活动通关；
  - 纪念品活动结束后仍然存在；
  - 棋盘、剧情、进度条的推进基本是同步的；
  - 剧情、进度条推进条件是一级物品新的 LV，棋盘解锁条件是指定 LV 的一级物品和满级钥匙。
- 满级面包喂给人物，获得三级物品心形宝石和书本（三级来源）；
- 钻石和心形宝石为积分物品，增加积分；
  - 积分用于解锁等级奖励，积分满级后，积分兑换积分宝箱。
- 书本作为宝箱物品，二合过程获得货车，满级作为书本宝箱获得奖励物品。

# 四、体验和结束

## 1. 体验

先提示玩家活动开启，随着主玩法的进行自然获得活动次数，开始尝试活动。

二合、格子解锁、钥匙解锁区域、上方场景剧情切换，获得金币、体力、货车等奖励。

差一点解锁下个区域时，活动同时给少量体力，推动玩家返回主玩法，从而形成循环。

过程的爽点在于三级物品链：合成一级物品会掉落二级物品和奖励，二级满级获得三级物品和奖励，有大量物品可以二合，提供给玩家整理。

剧情和逐渐解锁的地图推动玩家探索，最后一级 LV15 解锁的钥匙作为纪念品收集。

卡点：次数限制，玩法需要玩主玩法；存在“差一点就可以合成到下个 LV”的状态。

## 2. 结束

活动结束时不再开放合成，剩余资源按下一节处理。

## 3. 剩余资源处理

- 剩余未领取的金币、体力、货车、帽子登录后发放；
- 钥匙收集图鉴保留；
- 其余为活动一次性物品，删除。
